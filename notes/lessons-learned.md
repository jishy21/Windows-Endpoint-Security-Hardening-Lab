# Lessons Learned

## Overview
This document summarizes key concepts and technical skills learned during the Windows Endpoint Security Hardening Lab.

---

# Active Directory Security

I learned how Active Directory can be used to separate standard users from administrative users through security groups and least privilege access controls.

I also learned how improper privilege assignment can increase security risk inside an environment.

---

# Group Policy Management

I practiced using Group Policy to apply security settings across Windows systems.

This included:
- Password policies
- Account lockout policies
- Audit policies
- Security baselines

I learned how centralized policy management improves consistency and security in enterprise environments.

---

# Endpoint Hardening

I learned how endpoint hardening reduces the attack surface of a workstation.

This included:
- Disabling outdated protocols
- Configuring Windows Defender Firewall
- Verifying antivirus protections
- Restricting unnecessary network access

---

# Security Monitoring

I learned how Windows audit logs can help detect suspicious activity and track authentication events.

I also practiced navigating Event Viewer and reviewing security-related logs.

---

# PowerShell Administration

I gained experience using PowerShell commands to:
- Check Windows features
- Disable SMBv1
- Verify endpoint configurations

This improved my understanding of basic Windows administration and security management.

---

# Multi-Factor Authentication

I learned how MFA improves account security by requiring multiple authentication factors during login.

This demonstrated the importance of layered authentication protections.

---

# Real-World IT Security Concepts

This lab reinforced several CompTIA Security+ concepts including:
- Least privilege
- Defense in depth
- Secure authentication
- Vulnerability mitigation
- Attack surface reduction
- Logging and monitoring

---

# Overall Outcome

This project improved my understanding of Windows security administration, endpoint hardening, Active Directory management, and basic cybersecurity operations in a hands-on lab environment.
